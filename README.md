# Cena da Coesão

Jogo de estudo da coesão gramatical e lexical (Português, ensino secundário).

- **Definições**: o que é cada coesão e para que serve, com quiz.
- **Decorar os nomes**: mapa completo para preencher de memória e jogo «Qual falta?».
- **Adivinhar a coesão**: 175 frases e versos de Cesário Verde, em três níveis, com escolha múltipla ou resposta escrita.

Tudo está num único ficheiro, `index.html`, sem dependências além das Google Fonts.
